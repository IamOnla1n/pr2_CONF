# Вариант №15

Разработать инструмент визуализации графа зависимостей для менеджера пакетов. Готовые средства (менеджеры пакетов, библиотеки) для получения зависимостей использовать нельзя.

## Этап 1. Минимальный прототип с конфигурацией

**Цель:** создать минимальное CLI-приложение и сделать его настраиваемым.

**Требования:**

1. Источником настраиваемых пользователем параметров являются опции командной строки.
2. К настраиваемым параметрам относятся:
   - Имя анализируемого пакета.
   - URL-адрес репозитория или путь к файлу тестового репозитория.
   - Режим работы с тестовым репозиторием.
   - Версия пакета.
   - Имя сгенерированного файла с изображением графа.
3. (только для этого этапа) При запуске приложения вывести все параметры, настраиваемые пользователем, в формате ключ-значение.
4. Реализовать и продемонстрировать обработку ошибок для всех параметров.
5. Результат выполнения этапа сохранить в репозиторий стандартно оформленным коммитом.

## Функции валидации

### `validate_package_name(name)`
**Назначение:** Валидация имени пакета

**Логика:**
- Проверяет, что имя не пустое
- Проверяет допустимые символы: буквы, цифры, `.`, `-`, `_`
- **Возвращает:** очищенное имя пакета
- **Исключения:** `ValueError` при невалидном имени

### `validate_url(url)`
**Назначение:** Валидация URL или пути к файлу

**Логика:**
- Проверяет HTTP/HTTPS URL или существование локального файла
- **Возвращает:** очищенный URL или путь
- **Исключения:** `ValueError` при невалидном URL или отсутствующем файле

### `validate_filename(filename)`
**Назначение:** Валидация имени выходного файла

**Логика:**
- Проверяет поддерживаемые расширения: `.png`, `.jpg`, `.jpeg`, `.svg`, `.pdf`
- Проверяет отсутствие запрещенных символов в имени файла
- **Возвращает:** очищенное имя файла
- **Исключения:** `ValueError` при невалидном имени файла

### `validate_version(version)`
**Назначение:** Валидация версии пакета

**Логика:**
- Проверяет базовый формат версии
- **Возвращает:** очищенную версию
- **Исключения:** `ValueError` при невалидной версии

## Основная функция `main()`

**Назначение:** Точка входа в приложение, обработка аргументов командной строки

**Аргументы командной строки:**

- **`--package`** (обязательный) - имя анализируемого пакета
- **`--url`** (обязательный) - URL репозитория или путь к файлу  
- **`--test-mode`** (опциональный) - режим тестового репозитория
- **`--version`** (опциональный) - версия пакета (по умолчанию: 'latest')
- **`--output`** (опциональный) - имя выходного файла (по умолчанию: 'dependency_graph.png')

**Обработка ошибок:**
- **`argparse.ArgumentError`** - ошибки парсинга аргументов
- **`ValueError`** - ошибки валидации параметров
- **`Exception`** - неожиданные ошибки
