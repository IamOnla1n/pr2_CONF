## Функции валидации

### `validate_package_name(name)`
**Назначение:** Валидация имени пакета

**Логика:**
- Проверяет, что имя не пустое
- Проверяет допустимые символы: буквы, цифры, `.`, `-`, `_`, `+`
- **Возвращает:** очищенное имя пакета
- **Исключения:** `ValueError` при невалидном имени

### `validate_url(url)`
**Назначение:** Валидация URL репозитория Ubuntu или пути к тестовому файлу

**Логика:**
- Проверяет HTTP/HTTPS URL или существование локального файла
- **Возвращает:** очищенный URL или путь
- **Исключения:** `ValueError` при невалидном URL или отсутствующем файле

### `validate_filename(filename)`
**Назначение:** Валидация имени выходного файла

**Логика:**
- Проверяет поддерживаемые расширения: `.png`, `.jpg`, `.jpeg`, `.svg`, `.pdf`
- Проверяет отсутствие запрещенных символов в имени файла
- **Возвращает:** очищенное имя файла
- **Исключения:** `ValueError` при невалидном имени файла

### `validate_version(version)`
**Назначение:** Валидация версии пакета

**Логика:**
- Проверяет базовый формат версии пакетов Ubuntu
- **Возвращает:** очищенную версию
- **Исключения:** `ValueError` при невалидной версии

- **Возвращает:** список имен пакетов-зависимостей

## Основные функции

### `build_dependency_graph_bfs(start_package, get_dependencies_func, max_depth)`
**Назначение:** Построение графа зависимостей алгоритмом BFS с рекурсией

**Логика:**
- Рекурсивно обходит зависимости с помощью BFS
- Обнаруживает и обрабатывает циклические зависимости
- **Возвращает:** граф зависимостей в виде словаря

### `calculate_download_order(start_package, get_dependencies_func, max_depth)`
**Назначение:** Определение порядка загрузки зависимостей

**Логика:**
- Использует топологическую сортировку для определения порядка
- Обрабатывает циклические зависимости
- **Возвращает:** кортеж (порядок загрузки, граф зависимостей)

### `print_download_order_analysis(start_package, download_order, dependency_graph)`
**Назначение:** Анализ порядка загрузки и сравнение с реальным менеджером пакетов

**Логика:**
- Выводит порядок загрузки в нумерованном списке
- Анализирует возможные расхождения с реальным менеджером пакетов
- Объясняет причины различий в порядке загрузки

### `analyze_download_order(package_name, version, repo_url, test_mode)`
**Назначение:** Основная функция анализа порядка загрузки

**Логика:**
- Координирует процесс определения порядка загрузки
- **Возвращает:** кортеж (порядок загрузки, граф зависимостей)

### `get_dependencies_func_factory(repo_url, test_mode)`
**Назначение:** Фабрика функций для получения зависимостей

**Логика:**
- Создает функцию для получения зависимостей в зависимости от режима
- **Возвращает:** функцию для получения зависимостей пакета

### `get_package_dependencies_ubuntu(package_name, version, repo_url, test_mode)`
**Назначение:** Получение графа зависимостей пакета

**Логика:**
- Координирует процесс построения графа зависимостей
- **Возвращает:** полный граф зависимостей

### `main()`
**Назначение:** Точка входа в приложение, обработка аргументов командной строки

**Аргументы командной строки:**

- **`--package`** (обязательный) - имя анализируемого пакета
- **`--url`** (опциональный) - URL репозитория Ubuntu или путь к файлу тестового репозитория
- **`--test-mode`** (опциональный) - режим работы с тестовым репозиторием
- **`--version`** (опциональный) - версия пакета (по умолчанию: 'latest')
- **`--output`** (опциональный) - имя выходного файла (по умолчанию: 'dependency_graph.png')
- **`--download-order`** (опциональный) - режим вывода на экран порядка загрузки зависимостей

**Обработка ошибок:**
- **`ValueError`** - ошибки валидации параметров
- **`Exception`** - неожиданные ошибки
